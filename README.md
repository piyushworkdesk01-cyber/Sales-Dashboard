# 📊 Sales Dashboard – Microsoft Excel

## 📌 Project Overview
A professional and interactive Sales Dashboard created in Microsoft Excel to analyze sales performance, revenue trends, product performance, and key business metrics. The dashboard converts raw sales data into clear and actionable insights using PivotTables, PivotCharts, KPIs, and interactive filters.

## 🎯 Objectives
- Track overall sales performance
- Analyze revenue and sales trends
- Identify top-performing products and categories
- Compare regional performance
- Monitor key performance indicators (KPIs)
- Provide an easy-to-use interactive dashboard for decision-making

## 🛠️ Tools & Skills
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- KPI Analysis
- Data Cleaning
- Data Visualization
- Interactive Filters / Slicers

## 📈 Dashboard Features
- Total Sales and KPI cards
- Sales trend analysis
- Product and category performance
- Regional sales analysis
- Interactive charts
- PivotTable-based analysis
- User-friendly dashboard layout

## 💡 Key Insights
The dashboard helps users quickly identify sales trends, high-performing products and regions, and areas that may require attention. Interactive filters allow users to explore the data from different perspectives.
